## 🇬🇧 English Version

> The first level of Fabric Arcade is played with your arrow keys. Literally. 🏎️

**Fabric Racing Game** is a real HTML5 game running inside a Fabric notebook. As you grab ⭐ and dodge 🐛 across 10 tracks (Lakehouse Lane, Spark Summit…), every event streams in real time through an **Eventstream** into an **Eventhouse**, ready for KQL.

You're actually learning **Real-Time Intelligence** without noticing:
📡 Custom Endpoint for ingestion
🌊 Eventstream with JSON mapping
⚡ sub-second latency events on a KQL table

Then the challenge: build your own **Pit Wall** — a live dashboard, F1-team style.

One command and you're on track:
