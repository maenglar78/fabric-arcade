## Legend

### Difficulty Levels
- **Beginner** - No prior Fabric experience needed
- **Intermediate** - Basic understanding of Fabric concepts required
- **Advanced** - Experience with multiple Fabric workloads recommended

### Types
- **Accelerator** - Complete end-to-end solution with all components
- **Tutorial** - Step-by-step learning experience
- **Demo** - Quick showcase of specific capabilities
- **Challenge** - Mini-project focused on specific skills

### Workloads
- **Real-Time Intelligence** - Eventstream, Eventhouse, KQL, Real-Time Dashboard
- **Data Engineering** - Spark, Lakehouse, Notebooks
- **Data Science** - ML Models, Experiments, Predictions
- **Data Factory** - Pipelines, Dataflows
- **Power BI** - Reports, Semantic Models, Dashboards
