📋 Overview

You inherit the keys to the Arcade Hall: a Direct Lake semantic model packed with decades of high-scores from 12 arcade classics (Pac-Man, Galaga, Donkey Kong, Asteroids…) played by 40 handles across 8 cabinets.

Your mission: build a Power BI report that climbs 5 levels, each worth 20 points. The Check notebook reads your report's PBIR definition via sempy, grades each level independently, assigns a rank, and mints a signed HMAC badge. No DAX required — this is pure report craft.

🚀 Quick Start

# In any Fabric notebook
%pip install -q fabric-arcade

from fabric_arcade import arcade
arcade.install("retro-arcade", workspace="My Workspace")
# Provisions: Arcade_LH (Lakehouse), 01_Setup, 02_Quest, 03_Check notebooks.

Then open 01_Setup, run all cells (seeds the lakehouse + builds ArcadeHall_Model Direct Lake semantic model). Open 02_Quest for the brief, build your report named Arcade_Hall_Report, then run 03_Check.

🧩 How You Play

  1. 📖 01_Setup generates synthetic Scores / Games / Players / Cabinets / Date tables and builds ArcadeHall_Model with relationships + 7 base measures.
  2. 📜 02_Quest details the 5 levels (Foundation, Visuals, Interactivity, Storytelling, Polish).
  3. 🎨 In the workspace: + New → Power BI report → Pick a published semantic model → ArcadeHall_Model. Save as Arcade_Hall_Report.
  4. ⚒️ Build the report following the 5 levels.
  5. ⚖️ Run 03_Check any time — it fetches your PBIR via sempy.fabric.get_report_definition, parses pages/visuals/bookmarks/theme, scores 0–100, mints your badge.

🎯 The 5 Levels

🟢 LEVEL 1
Foundation
20 PTS
≥3 pages, meaningful page titles, page backgrounds applied.
🟡 LEVEL 2
Pixel Perfect
20 PTS
≥5 unique visual types. Must include at least 1 Card and 1 Slicer.
🟠 LEVEL 3
Combo Move
20 PTS
≥2 slicers, ≥1 sync slicer across pages, edit-interactions configured.
🟣 LEVEL 4
Bonus Stage
20 PTS
≥1 bookmark, ≥1 tooltip page, ≥1 drill-through page.
🔵 LEVEL 5
High Score
20 PTS
Custom theme, conditional formatting on ≥1 visual, mobile layout on ≥1 page.

📦 What Gets Installed

  • 🏠 Lakehouse Arcade_LH — seeded by 01_Setup with Scores (~80k), Games (12), Players (40), Cabinets (8), Date (3 yrs).
  • 📓 3 Notebooks: 01_Setup, 02_Quest, 03_Check.

The semantic model ArcadeHall_Model is built at runtime by 01_Setup via sempy-labs Direct Lake (with relationships + 7 base measures pre-defined so you can drag-and-drop right away).
