Calc Groups Cathedral

Replace 12 redundant time-intelligence measures with one elegant Calculation Group on a real Direct Lake semantic model. Earn the rank of Cathedral Builder.

Difficulty⭐⭐⭐ Advanced
Deploy Time~3 min
Complete Time~60 min
Status✅ Ready · v1.0.0
"An apprentice writes a measure for every KPI variation. A master architect carves one calculation group and lets the cathedral build itself."

📋 Overview

You are the Chief Architect of the Vertipaq Cathedral. Twelve KPI pillars need to live on a real Direct Lake semantic model: Current, LastYear, YoY, YoY%, YTD, MTD, QTD, Rolling12, BestMonth, %OfYear, AvgDailySales, DistinctCustomers.

The apprentice's way: 12 measures, each one re-typing the same SUM(Sales[Amount]). The architect's way: 1 base measure + 1 Calculation Group with 11 items (DistinctCustomers stays standalone — it changes the aggregation, not the time context). Every submission is graded for correctness on 3 contexts and rewarded with an elegance score that penalizes long DAX, redundant CALCULATE, and unnecessary FILTER / SUMX.

🚀 Quick Start

# In any Fabric notebook
%pip install -q fabric-arcade

from fabric_arcade import arcade
arcade.install("calc-groups-cathedral", workspace="My Workspace")
# Provisions: Cathedral_LH (Lakehouse), Cathedral_EH (Eventhouse + CathedralEvents table),
#             01_Setup, 02_Quest, 03_Check, 04_Dashboard notebooks.

Then in the new workspace: open 01_Setup and run it once (synthetic data → Lakehouse → Direct Lake Cathedral_Model with the seed measure). Open 02_Quest, build your pillars on Cathedral_Model, then run 03_Check to submit. Track progress in 04_Dashboard.

🧩 How You Play

  1. 📖 01_Setup generates 3 years of synthetic Sales/Date/Customer/Budget and builds Cathedral_Model with the seed measure [Sales Amount Seed] = SUM(Sales[Amount]).
  2. 📜 02_Quest shows the 12 pillar specs and the Final Challenge brief.
  3. ✍️ Open Cathedral_Model in the Fabric web UI (or use sempy-labs from any notebook) and author measures M_01_Current … M_12_DistinctCustomers.
  4. 🏛️ Build the calculation group 'Time Intelligence'[Calc] with 11 items wrapping SELECTEDMEASURE().
  5. ⚖️ Run 03_Check — it evaluates each pillar via DAX on 3 contexts, scores elegance, assigns rank, and ships PillarPassed / PillarFailed / RankPromoted events to KQL.
  6. 📊 04_Dashboard renders a live Plotly view of your run: state, timeline, measures vs calc group, session recap.

📦 What Gets Installed

  • 🏠 Lakehouse Cathedral_LH — populated at runtime with Sales / Date / Customer / Budget Delta tables (3 years).
  • ⚡ Eventhouse Cathedral_EH + table CathedralEvents (15 columns, PascalCase, 90d retention).
  • 📓 4 Notebooks: 01_Setup, 02_Quest, 03_Check, 04_Dashboard.

The semantic model Cathedral_Model is built at runtime by 01_Setup (via sempy-labs / TOM), so it does not appear in the install plan — but it is created in the same workspace as part of the first run.

🏛️ The Final Challenge — One Calc Group, 11 Items

Collapse pillars 1 through 11 into a single Calculation Group:

// table 'Time Intelligence', column [Calc], 11 calc items
// Each item wraps SELECTEDMEASURE() — applies to any base measure
Current     = SELECTEDMEASURE()
LastYear    = CALCULATE(SELECTEDMEASURE(), SAMEPERIODLASTYEAR('Date'[Date]))
YoY         = SELECTEDMEASURE() - CALCULATE(SELECTEDMEASURE(), SAMEPERIODLASTYEAR('Date'[Date]))
YoYPct      = DIVIDE(/* YoY */, /* LY */)
YTD         = CALCULATE(SELECTEDMEASURE(), DATESYTD('Date'[Date]))
MTD         = CALCULATE(SELECTEDMEASURE(), DATESMTD('Date'[Date]))
QTD         = CALCULATE(SELECTEDMEASURE(), DATESQTD('Date'[Date]))
Rolling12   = CALCULATE(SELECTEDMEASURE(), DATESINPERIOD('Date'[Date], MAX('Date'[Date]), -12, MONTH))
BestMonth   = MAXX(VALUES('Date'[MonthNum]), SELECTEDMEASURE())
PctOfYear   = DIVIDE(SELECTEDMEASURE(), CALCULATE(SELECTEDMEASURE(), ALL('Date'[MonthNum], 'Date'[Quarter])))
AvgDaily    = AVERAGEX(VALUES('Date'[Date]), SELECTEDMEASURE())

Why 11, not 12? DistinctCustomers swaps the aggregation entirely (DISTINCTCOUNT vs SUM) — it isn't a time-context shift, so it belongs outside the group.
