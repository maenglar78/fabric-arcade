✨ Features

🎯

Learn by Doing

Each game creates real resources in your Fabric workspace. Learn by building, not watching.

🏆

Achievement System

Unlock badges by completing objectives. Show your skills to the world!

📊

Real Workloads

RTI, Spark, Warehouse, Power BI - all Fabric workloads in gaming format.

⚡

One-Click Deploy

One command to deploy the entire game environment to your workspace.

🔄

Iterative Learning

Arcade (5 min) → Challenge (15 min) → Mission (45 min). Grow at your own pace.

🌐

Open Source

Contribute new games, improve existing ones. Community-driven.

🚀 Get Started

1

Install

pip install fabric-arcade
2

Choose

arcade.list_games()
3

Deploy

arcade.install("fabric-racing-game")
4

Play!

arcade.play("fabric-racing-game")

📋 Requirements

  • Python 3.9+
  • Microsoft Fabric workspace (F2+ capacity)
  • Azure CLI logged in (az login)
