Open Source

Everything you see — the Python library, the catalog, every game's notebooks and KQL schemas, this very website — is on GitHub. Fork it, break it, ship a PR.

📦 What's in the repo

🐍
fabric_arcade/
The Python package: catalog, REST client, install/uninstall, badge signing.
🎮
catalog/
One folder per game: manifest.json, KQL schemas, notebooks, README.
🌐
website/
This site. Plain HTML + CSS, served by GitHub Pages from main.
🛠️
dev/
Build & upload scripts used while authoring new games (Cathedral notebooks, etc.).
📚
docs/
Getting-started, design notes, and contributor guidelines.
🧪
tests/
Unit tests for catalog parsing, badge signing and REST helpers.

➕ Add your own game

A game is just a folder in catalog/ with a manifest.json that lists items, notebooks and tables. The library reads it dynamically — no Python changes required for new content.

  • Define your items (Lakehouse / Eventhouse / Notebook / ...)
  • Drop your .kql schemas and .ipynb notebooks alongside
  • Add an entry to catalog_index.json
  • (Optional) Add a card to the website's index and a detail page
  • Open a PR — that's it
