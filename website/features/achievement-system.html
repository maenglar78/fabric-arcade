Achievement System

Every game ships with a cryptographically-signed badge you can earn, download as PNG/SVG and share on LinkedIn. No "Verified by trust me bro" — the signature is HMAC-SHA256 and can be checked by anyone.

🎖️ How it works

When you complete a game's challenge, the validation notebook computes your score and rank, then builds a payload:

{ "g": "calc-groups-cathedral", "p": "Mauro", "r": "Cathedral Builder",
  "s": 1850, "t": 1780058205, "v": 1 }

The payload is signed with a shared HMAC key. The badge page (/badge.html?t=…) re-runs the same HMAC with the Web Crypto API and shows ✓ Signature verified before rendering. Anyone receiving your link can verify it without contacting any server.

📈 Ranks (example: Calc Groups Cathedral)

Each game can define its own progression. Cathedral uses five masonry-themed ranks based on your elegance score:

🪨 Stonemason · 0+ 🔨 Apprentice · 300+ ⚒️ Journeyman · 700+ 📐 Architect · 1100+ 🏛️ Cathedral Builder · 1500+

📤 Sharing

Once your badge URL is generated, the badge page provides:

  • ⬇️ Download as PNG (LinkedIn-ready) or SVG (vector)
  • 🔗 Direct Share on LinkedIn / X buttons
  • 📋 Copy link with the signed token embedded
  • ✓ Anyone visiting the link sees the same "Signature verified" check
