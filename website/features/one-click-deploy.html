FEATURE

One-Click Deploy

From "I want to play" to "the game is running in my workspace" in a single arcade.install() call.

🚀 The whole thing

# In a Fabric Notebook (or local Python with az login):
%pip install -q fabric-arcade

from fabric_arcade import arcade
arcade.list()
arcade.install("calc-groups-cathedral")

That is it. Behind the scenes the library logs in via az credentials, resolves your current workspace and provisions every required item for that game.

⚙️ What happens under the hood

  • 📥 Fetches the game manifest and assets from the public GitHub catalog
  • 🏠 Creates Lakehouses, Eventhouses, Eventstreams, Notebooks via Fabric REST APIs
  • 🗄️ Runs the KQL schema scripts against the new KQL Database to create tables and policies
  • 📓 Uploads each notebook (InlineBase64) into the workspace
  • 📜 Generates a per-game README notebook with the exact next steps
  • ✅ Returns the list of created item IDs so you can script further

🧹 Equally easy to remove

arcade.uninstall("calc-groups-cathedral")

Deletes the items created by the install. Useful when demoing on a shared capacity.

🛡️ Idempotent & transparent

If an item with the same name already exists, the install is non-destructive: it will surface the conflict instead of overwriting. Every REST call is logged so you can copy the pattern for your own deployment scripts.
